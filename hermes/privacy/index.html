Privacy Policy – Hermes Agent GW

Last updated: November 11, 2026

Hermes Agent GW is a private tool used only by its owner, Si Huynh, to connect his own Google accounts to an AI assistant running on his own computer.

Data accessed

With the owner's consent via Google OAuth, the tool may access Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets and Google Contacts data of the signed-in account.

How data is used

Data is used only to fulfil the owner's own requests (for example reading a document or drafting an email). Sending email, editing or sharing files, and changing calendar events happen only after the owner approves each action.

Storage and sharing

OAuth tokens are stored locally on the owner's computer. No Google user data is sold, shared with third parties, or used for advertising. Content passed to the AI model provider is processed only to answer the owner's request.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
